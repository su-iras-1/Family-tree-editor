# 家谱编辑器 · 使用说明

> **整理：黑泥17514** · 2026-09-28

一个**单文件、离线可用**的家谱图（genogram）编辑器，功能对标 genogrampro.com 的免费家谱图制作器(要会员来保存)，并按中文家谱的使用习惯做了增强。全部数据保存在你自己的电脑上，不上传任何服务器。

打开方式：**双击 `家谱编辑器.html`**，用浏览器打开即可。不需要联网、不需要安装、不需要注册。

## 二、一分钟上手

1. 打开后画布上只有一个人：**「我」**。
2. 单击选中他，节点四周会出现四个蓝色 **＋** 号：

   ```
                 ＋  ← 加父母（自动配成一对夫妻）
                 │
      加配偶 ＋ ── □ ── ＋ 加兄弟姐妹
                 │
                 ＋  ← 加子女
   ```
3. 在右侧面板填写**姓名、性别、出生年**。填了出生年，兄弟姐妹、堂表亲的「长幼」就会自动区分（大哥 / 二弟），同辈里的**年长者始终排在左边**。
4. 反复用 ＋ 号往外铺开，一张家谱就长出来了。想调整位置就直接**拖动节点**；点顶部「自动排列」恢复整齐。
5. 点右上角「导出」，选 PNG 或 PDF。

> 键盘的**方向键**可以直接平移画布：按住不放会连续移动，按住 Shift 加速，同时按住两个方向键可以走对角线。鼠标停在哪个输入框里，方向键就归那个输入框用（比如在出生年里左右移动光标），不会把画布带走。

> 左侧第一个工具叫「**框选**」：在空白处拖出方框＝一次选中一片；在人物上按下＝立刻选中他，接着拖就是移动。详见第六节。

> 画布右上角的**图例默认是关着的**（挡视线），要看时在左侧「视图」里勾「显示图例」。

> 有些亲戚在结构上讲不清（只知道两人是兄弟、却不知道父母是谁），用左侧「**关系线**」直接点两个人声明一条血缘，自动排列就会按它把辈分排对。详见第三节。

> 左侧工具栏与节点上的 ＋ 号功能完全一样，也可以用菜单操作。所有新增的成员都会**立即自动保存**到浏览器，关掉标签页再打开还在。

## 三、符号约定（McGoldrick 家谱图通用画法）

### 人物符号

| 符号 | 含义 |
|---|---|
| □ 方块 | 男性 |
| ○ 圆圈 | 女性 |
| ◇ 菱形 | 性别未知 / 未填 |
| 符号上打 × | 已故（同时显示生卒年） |
| 方块内嵌小圆 | 跨性别（女→男） |
| 圆圈内嵌小方 | 跨性别（男→女） |
| 符号内实心三角 | 同性恋 |
| 符号内彩色扇形 | 健康状况 / 自定义彩色标记（可在图例中说明） |
| 符号左下角小圆章「**赘**」 | 入赘（男到女家）——这是**资料选项**，不只是标记，会改变排版（见第五节） |

### 夫妻线

| 画法 | 含义 |
|---|---|
| 实线 | 婚姻 |
| 长虚线 | 同居 |
| 点线 | 订婚 |
| 单斜杠 | 分居 / 丧偶 |
| 双斜杠 | 离异 |
| 绕到下方折线 | 再婚（同一人的第二、第三段关系） |

### 亲子线

| 画法 | 含义 |
|---|---|
| 实线 | 亲生 |
| 长虚线 | 收养 |
| 点线 | 寄养 |
| 长短交替虚线 | 继子女 |
| **极淡的细虚线（直角走线）** | 出嫁 / 入赘者从本家姊妹位绕到自己位置的来路（见第五节，可关） |

### 情感关系线（可加在任意两人之间）

| 画法 | 含义 |
|---|---|
| 双平行线 | 亲密 |
| 三重平行线 | 融合 / 纠缠 |
| 虚线 | 疏远 |
| 锯齿线 | 冲突 |
| 中间断开 | 断绝来往 |
| 加重锯齿 | 敌对 |

添加情感线：左侧点「情感关系线」，然后依次点两个人；或者在右侧面板点「＋ 与某位成员添加情感线」。

**竖线穿过横杆处会画一个小半圆「跳线」**，表示两条线只是交叉、并不相接，避免看错归属关系。

### 关系线（自定义血缘）

有些血缘关系在结构上画不出来——比如只知道两个人是兄弟，却不知道他们的父母是谁；或者一位远房长辈，中间几代都没录。用「**关系线**」直接声明一条血缘，**自动排列**就会按它把人排到合适的辈分上。

| 画法 | 含义 | 辈分效果 |
|---|---|---|
| 棕实线 + 箭头 | **生**：先点的人 生了 后点的人 | 后点的人低一辈 |
| 棕实线 + 箭头 | **被生**：先点的人 是被后点的人生的 | 后点的人高一辈 |
| 青绿双线 | **兄弟姐妹** | 两人同辈（同一行） |
| 棕长虚线 + 箭头 | **领养**：先点的人是养父母 | 后点的人低一辈 |
| 棕点划线 + 箭头 | **过继**：后点的人过继到先点的人名下 | 后点的人低一辈 |
| 灰点线 + 箭头 | **自定义** | 由你指定辈分差 n |

- **箭头**指向「**后点的那个人**」；一条线的意思永远是「先点的人 → 后点的人」。
- 线的**中点挂一个小标签**写着是什么关系；**点标签就能改**（改类型、改辈分差、改文字，或删掉）。右侧属性面板里也有「血缘关系线」一小节，逐条列出、可改可删。
- 添加方式：左侧点「**关系线**」，依次点两个人，再在弹层里选一种；工具会一直开着，可以接着点下两个人继续加。

**「自定义」**是给说不清具体称呼的场合用的：只填一个**辈分差 n**（正数＝后点的人低 n 辈，负数＝高 n 辈，0＝同辈），再可选填一个名字（如「堂兄」「表哥」「兼祧」）。它**不说明是什么亲戚**，自动排列也不会拿它当亲子或兄弟姐妹去解释，只按 n 把对方挂到合理的那一辈上。

**关系线只管辈分，不动结构**：它不会把两个人并成一家人，也不会改写亲子线。已有父母、子女、夫妻、兄弟姐妹关系算出来的辈分**优先**，关系线只补结构没覆盖到的人。所以被关系者是「挂在主体家族旁边的一个挂件」——辈分对了，家族块还是各归各的。详见第四节。

## 四、自动排列怎么排

点顶部「自动排列」，会清掉所有手动拖动，按下面三条规则重新排布。任何时候想恢复整齐，点它就对了。

**① 以中心人物（「我」）为准推算辈分：同辈的人一定落在同一行。**

辈分的算法是：**中心人物记 0 代，父母少一辈（−1）、子女多一辈（+1），配偶与兄弟姐妹同辈**；再从中心人物出发沿关系网推一遍，最后整体平移到最上面那一辈。所以「同一行」＝「辈分相同」，与这支人记得深不深无关。

**关系线也参与这条推算**（见第三节）：一条「生 / 领养 / 过继」把后点的人压到下一辈，「被生」抬到上一辈，「兄弟姐妹」拉到同一行，「自定义」按你填的辈分差 n 走。规矩是**结构优先**——父母、子女、夫妻、兄弟姐妹这些实打实的关系算出来的辈分不会被关系线改写；关系线只补**结构没覆盖到的人**。补完之后，新落位的人自己带的父母 / 子女 / 配偶也跟着一起落位。

这一点很重要。以前的算法是「没有父母的人算第 0 代」，于是谁家的谱系记得浅，谁就被顶到最上面去：镇江那份谱里，**外公外婆原本被放到了曾祖父那一行**（因为只记到外公，没记外公的父母），**舅舅、姨妈被放到了爷爷奶奶那一行**，表兄弟姐妹也被顶高了一辈。现在按中心人物推算，全部回到自己该在的行：

| | 旧算法（无父母者＝0 代） | 现在（以中心人物推算） |
|---|---|---|
| 第 0 代 | 曾祖父、曾祖母、外曾祖父、外曾祖母、**外公、外婆** | 曾祖父、曾祖母、外曾祖父、外曾祖母 |
| 第 1 代 | 爷爷奶奶、伯公叔公姑奶奶、舅爷爷姨奶奶、**舅舅、舅母、姨妈、姨父** | 爷爷奶奶、外公外婆、伯公叔公姑奶奶、舅爷爷姨奶奶 |
| 第 2 代 | 爸爸妈妈、伯叔姑舅姨、**表兄弟姐妹（舅表 / 姨表）** | 爸爸妈妈、伯叔姑舅姨、舅舅舅母姨妈姨父 |
| 第 3 代 | 我、兄弟姐妹、堂表兄弟姐妹 | 我、兄弟姐妹、堂表兄弟姐妹、表兄弟姐妹（舅表 / 姨表） |

> 一行里排到哪一位，仍是「先按最高辈分的那对夫妻定位」——先找出辈分最高的一对夫妻（通常是最老的祖先），把它放在整幅图的基准位置，其余家族再围绕它铺开。中心人物的直系祖先优先当这个基准。

**② 父系为主轴，夫左妻右。** 每对夫妻里，**丈夫在左、妻子在右**（传统家谱的「男左女右」）；一对夫妻的子女算在父系这一支下面。这样从上往下的那条主线（父 → 子 → 孙）会连成一条清楚的轴线，母亲那边的亲戚则作为姻亲挂在两侧。

**③ 亲族分块：本家 → 奶奶一族 → 外公一族 → 外婆一族，依次类推。**

每个家族块摆在哪一边，是由**它和中心人物的亲缘路径**定死的：从中心人物往上走，**父系方向记 0、母系方向记 1**，一路上走出来的编码越小越靠左。

| 家族块 | 代表它的人 | 路径编码 | 排第几块 |
|---|---|---|---|
| 本家（爷爷一族） | 爸爸的爸爸…… | （空） | 1 |
| 奶奶一族 | 爸爸的妈妈 | 01 | 2 |
| 外公一族 | 妈妈的爸爸 | 10 | 3 |
| 外婆一族 | 妈妈的妈妈 | 11 | 4 |
| 再往上（曾祖辈那一层） | 依次类推 | 00、001…… | 继续往右 |

所以整幅图**从左到右读，就是「先本家、再奶奶家、再外公家、再外婆家」**。镇江亲属称呼谱的实际结果（只取了最靠左的三个家族块）：

| 家族块 | 最左那个人的位置 |
|---|---|
| 本家（曾祖父、曾祖母） | x ≈ 1082 |
| 奶奶一族（外曾祖父、外曾祖母） | x ≈ 2436 |
| 外公一族（外公、外婆） | x ≈ 2814 |

> 这个次序是**固定的**：同一份数据，每次排出来都在同一处，不会因为线条长短偶然换边。选它的理由是家谱要能一眼对上「这一块是谁家」；代价是**子代线不再保证最短**——程序不再为了省几行线长而把某个家族换到另一边去。
>
> **嫁出去的人怎么放**，见下一节；**同辈之间**仍是按排行／出生年，年长的在左（见第八节）；**只靠关系线连过来的家族块**排在本家之后、其余姻亲之前。
>
> 唯一会改变这个次序的是**入赘**：谁勾了「赘 · 入赘」，谁就算进女方那一块，女方一族随之顶到最左边（见第五节）。

## 五、出嫁 / 入赘：本人画在婚后所在的家族，来路用淡线

传统家谱是父系谱：女儿出嫁后，她这一支记在夫家。编辑器照这个习惯画，但**不丢掉她在本家的位置**。反过来「男方到女方家」（入赘）也照同一套画，只是门户按女方算——**这一项默认不勾，要在属性面板里手动选**，详见下面「赘 · 入赘」。

| | 画法 |
|---|---|
| 出嫁（或入赘）的人 | 只在**婚后所在的家族**画一个正常的实线符号，与丈夫（或妻子）并排，一起挂在对方家族块的下面 |
| 她与本家的关系 | 本家父母的那条子女横杆**照样横跨到她该在的位子**——按**姊妹排行**，她夹在兄弟姐妹中间；从那个位子拉一条**极淡虚线**，**直角转弯**（竖 → 横 → 竖）绕到夫家里她本人的符号顶端 |

也就是说：**「虚线」和「实线」地位完全相同**——同一个起点（父母横杆）、同一条横杆、同一套直角走线，只是深浅不同；她本人只画一处，不会同一个人出现两遍。镇江亲属称呼谱里被这样标记的有两位：

| | 在本家的姊妹位 | 本人所在的夫家位置 |
|---|---|---|
| 奶奶 | x ≈ 2347（在舅爷爷 x ≈ 2464、姨奶奶 x ≈ 2728 之前） | x ≈ 1064（爷爷旁边） |
| 妈妈 | x ≈ 3035（夹在舅舅 x ≈ 2842 与姨妈 x ≈ 3228 之间） | x ≈ 970（爸爸旁边） |

位子是按和其他子女**同一套排序规则**（先出生年、后兄弟排行）定出来的，所以她在本家的位置就是她真实的姊妹次序。

### 「赘 · 入赘」：一条会改排版的资料项

上一段说的「入赘」，在编辑器里是一条**真的资料**，不只是画个记号。选中任意一位**男性**，右侧面板「性别」下面会多出一个勾选框：

```
☑ 赘 · 入赘（男到女家）
```

**这一项只对男性出现**（改成女性会自动勾掉并提示）。勾上以后：

| | 变化 |
|---|---|
| 门户归属 | 这一对夫妻**门户按女方算**：整个小家庭（夫妻＋子女）搬到**女方那一族**下面排 |
| 夫妻次序 | **夫左妻右不变**——仍是丈夫在左、妻子在右 |
| 本人的来路 | 他自己本家那边**照样留一个姊妹位**，用同一条极淡虚线直角连过来，与出嫁的女儿完全一样 |
| 符号 | 他的方块**左下角多一个小圆章「赘」**（琥珀色），图例里会多一行「赘：入赘（男到女家，门户按女方算）」 |
| 家族块次序 | 家族块是按「块里离中心人物最近的那位祖先」定次序的（见第四节）；他入赘之后就算进了女方那一块，于是**女方一族顶到最左边**，原来的本家整块右移，整幅图的主轴跟着换到女方这一支 |

在镇江亲属称呼谱上把「赘」勾在**爸爸**身上试过一遍，结果是：

| | 勾上「赘」之前 | 勾上「赘」之后 |
|---|---|---|
| 爸爸 / 妈妈 | x ≈ 894 / 970（本家，爷爷奶奶一族） | x ≈ 706 / 782（外公外婆一族，丈夫仍在左） |
| 爸爸本家的姊妹位 | 无 | x ≈ 1971，夹在爷爷一族的子女横杆上，用淡线连到 x ≈ 706 |
| 本家（爷爷一族）的最左位置 | x ≈ 988 | x ≈ 2027 |
| 家族块次序 | 本家 → 奶奶 → 外公 → 外婆 | **外公一族 → 本家 → 奶奶一族 → ……** |
| 移动过的人 | — | 60 人全部挪位，最大位移 2830 px |

> 换言之，勾这一项是**在改门户归属，不是加一个图标**：因为「本家」的定义跟着换到女方那一支，家族块次序会整体重排。想好门户怎么算再勾，**不要一边手动微调位置一边勾**。

取消勾选立刻恢复成原来的排法。这一项**跟着 `.json` 一起保存**，别人打开你存的文件时看到的门户归属和你存的时候一致。

### 「母族关系用淡线」：这条线可以关掉

左侧工具条最下面「视图」一组里，有一个勾选框 **「母族关系用淡线」**：

| | 效果 |
|---|---|
| **勾选**（默认） | 本家按姊妹排行给她留一个位子，连到她本人的那条线＝极淡虚线，直角转弯 |
| **取消勾选** | 本家**不留位子**，她和普通子女一样从父母横杆直接画一条实线到自己在夫家的位置（也就是这条线会横穿画面） |

> 两种模式的**人物位置会略有不同**：留姊妹位会占一点横向宽度（每位 34 px），所以取消勾选后，那条横杆上的兄弟姐妹会往回收一点，连带右侧的家族块整体左移——镇江谱里 60 人中有 16 人会挪动几像素到一两百像素不等。切换开关时请不要正在手动微调位置。

> 这条淡线是**画的线，不是假的人物**：它占位置、参与排版，但**选不中**——选中集合里永远只有真实的成员符号；本家里要是没记录她的父母，自然也就没有这条线、也不留位子。

> 这个开关会**跟着 `.json` 一起保存**，别人打开你存的文件时看到的画法与你存的时候一致。

## 六、框选：一次选中一片

左侧工具条第一个工具就叫「**框选**」，它管两种拖法：

- 在**空白处**按下并拖出一个方框 → **框选**，松开后框里的成员一起被选中（判断标准是符号中心点落在框内）；
- 在**人物上**按下 → 这个人**当场就被选中**（不用先点一下再拖），接着拖就是移动他；松手时如果其实没拖动，就只是「点了一下」，选中他一个人。

右侧面板会立刻切成「已选中 N 位成员」。

| 操作 | 效果 |
|---|---|
| 空白处拖出方框 | 选中框内所有成员（原来的选择被替换） |
| **Shift** ＋ 拖方框 | 在原有选择上**追加**，不清掉已经选好的 |
| **Shift** ＋ 单击某人 | 把这个人加入 / 移出选择 |
| 单击空白处 | 取消全部选择 |
| 拖动选中的任意一位 | 选中的**所有人一起移动** |
| `Delete` | 把选中的成员**一次全部删除**（可 Ctrl+Z 撤销） |
| 在人物上**按下**（不用等松手） | 这个人立刻被选中；继续拖就是移动他 |
| 单击某一位未被选中的人 | 选择收拢为只选他 |
| 平移工具 / 空格 / Alt / 中键下**轻点**某人 | 同样是选中他（真的拖起来才是平移） |

多选状态下，右侧面板提供：

- **名单**：列出被选中的每个人及其称呼，点某一行就只看那一位；
- **批量修改**：把这些人一起设为男 / 女 / 性别未填；给这些人**一起加同一条彩色标记**（填个名字，如「高血压」，再选颜色，导出时会按图例显示）；
- **整体微调位置**：上移 / 下移 / 左移 / 右移；与手动拖动等效，点「自动排列」会归位；
- **取消选择** 与 **删除这 N 位成员**。

> 框选只影响画布上的位置与属性，不会改动亲属关系。被选中的节点会套上蓝色虚线方框，**缩放时线宽不变**，所以整幅图缩到 20% 也看得清选中的是谁。

**平移画布改到了别处**，因为空白处拖动现在是框选：点左侧的「**平移画布**」工具，或按住**空格**拖动、按住 **Alt** 拖动，用**鼠标中键**拖动，或者直接按**键盘方向键**——五个入口任选其一。用**鼠标的这四个入口**时**轻点人物依然是选中**，只有真的拖动起来才平移，所以「点谁选谁」在任何工具下都成立。滚轮缩放不受影响。

> 无论用上面哪一种方式选中（单击、Alt / 空格 / 中键轻点、Shift 追加、空白处框选），右侧属性面板都会**立刻**切到刚选中的人（多选时切到「已选中 N 位成员」），不用再点一次。

## 七、自动推算亲属称呼

选中任意成员，右侧最上方会显示**以「我」为基准的规范称呼**，并附关系路径与口语叫法：

```
   伯祖父（= 刘XX 应称其为）
   祖父的哥哥
   关系路径：父 → 父 → 兄弟
```

**推算原理**：在亲属关系图上用「父 / 母 / 夫 / 妻 / 子 / 女 / 兄 / 弟 / 姐 / 妹」九种步长做广度优先搜索，取最短关系路径；再把「父 + 子」这类两跳归约成「兄弟」一跳；最后按 **上溯 → 旁系 → 下延** 三段式生成称呼。

**已覆盖的范围**：

- 直系：父母、祖父母、外祖父母、曾祖 / 高祖……子女、孙辈、曾孙……（含「外」的正确用法：**祖母的父亲 = 外曾祖父**，**女儿的儿子 = 外孙**）
- 同辈：兄弟、姐妹、堂兄弟姐妹、表兄弟姐妹（自动区分姑表 / 舅表 / 姨表）
- 长辈旁系：伯父 / 叔父、姑母、舅父、姨母；伯祖父 / 叔祖父、姑祖母、舅祖父、姨祖母……
- 晚辈旁系：侄子 / 侄女、外甥 / 外甥女、侄孙辈；堂 / 表侄
- 姻亲：岳父 / 岳母、公公 / 婆婆、大舅子 / 小舅子、大伯子 / 小叔子、大姑子 / 小姑子、嫂子 / 弟媳、姐夫 / 妹夫、儿媳 / 女婿等

**两条要注意的规则**：

1. **长幼要靠出生年，年龄不明时靠「兄弟排行」**。两样都没有时，系统不会瞎猜，而是给出并列叫法，如「伯父 / 叔父」「堂兄弟」；把两人的出生年（或排行，见第八节）填上，就会自动变成「大伯」或「叔叔」。
2. **称呼可以自己改**。自动推算只是默认值，随时可以覆盖成家里实际叫的那一个。

### 改称呼：两种改法

节点上方那行**蓝色小字就是称呼**，它有两种来源——**自动推算**（默认）和**手工指定**（你自己填的）。手工指定永远优先。

**改法一：在画布上双击。** 双击节点上的蓝色称呼，就地弹出输入框，改完回车即可：

| 操作 | 效果 |
|---|---|
| 双击**蓝色称呼** | 修改称呼 |
| 双击名字 | 修改姓名 |
| 双击符号本身 | 有称呼就改称呼，否则改姓名 |
| `回车` / 点别处 | 保存 |
| `Esc` | 放弃本次修改 |
| 把内容**清空**后回车 | 删掉手工称呼，恢复自动推算 |

**改法二：右侧面板。** 「节点上显示的称呼（留空则自动推算）」一栏里直接写，效果一样；输入框为空的提示文字会告诉你此刻自动算出来的是什么。改过之后旁边会出现**「恢复自动」**按钮，一点就退回自动推算。

改称呼最常见的用法是记方言叫法，例如把自动算出的「小姑母」改成「姑妈（娘娘）」，或者把「伯祖父」改成本地叫的「大爷爷」。这个填写结果会跟着 `.json` 一起保存，导出图片时也照它显示。

## 八、兄弟排行：同辈谁大谁小

老谱里常常只写「老大、老二、老三」，未必记得住每个人的出生年。因此**「兄弟排行」是每个人一个可编辑的属性**（右侧面板「出生年 / 去世年」下面那一栏），和年龄挂钩，但各管一段：

| 情况 | 同辈怎么排 |
|---|---|
| **填了出生年** | 按出生年排，年长者在前；排行这一栏只是备注，不影响排序 |
| **没填出生年、填了排行** | 排行即「他在这辈里排第几」，1 ＝ 最大，直接据此占位 |
| **两样都没有** | 保持录入次序；称呼里的长幼并列显示（如「伯父 / 叔父」「哥哥 / 弟弟」） |

出生年与去世年两个输入框**只收数字、最多 4 位**（粘进来多余的东西会被自动剔掉），所以不会因为误敲字母或空格把排序搞乱。

也就是说：**年龄是硬依据，排行是年龄缺失时的替补**。同一辈里有的填了年、有的只填了排行，两种人会按各自的依据混排到一起，结果永远是**年龄大的排在前面、排行小的排在前面的**。

一个例子（同一对父母的三兄弟）：

```
阿二 1960 ┐
阿三 1965 ├─ 都填了出生年 → 按年龄排：阿二 > 阿三 > 阿大
阿大 1970 ┘（阿大即使被填成「排行 1」也不作数，年龄说了算）

阿二 排行1 ┐
阿大 排行2 ├─ 都没写出生年 → 按排行排：阿二 > 阿大 > 阿三
阿三 排行3 ┘

阿大 1975 ┐
阿二 排行1 ├─ 混着来 → 阿二 > 阿大 > 阿三
阿三 1980 ┘（阿二占了他声明的「第一位」，其余按年龄依次排）
```

排行不只是决定画布上的左右位置，还决定**称呼里的长幼**：父亲的哥哥叫「伯父」、弟弟叫「叔父」；同辈之间叫「哥哥 / 弟弟」还是「姐姐 / 妹妹」，都按同一套规则判断。堂表兄弟姐妹之间不比排行（排行只对同一对父母的亲兄弟姐妹生效），长幼仍以出生年为准。

> 面板里的提示会跟着变：填了出生年时会提醒你「同辈排序以出生年为准」；只有排行时则提示「同辈就按这条排行排位」。不做任何填写也不会出错，只是长幼并列显示。

## 九、导入你自己的数据

如果你已经有关系数据（比如本项目里的 `镇江亲属谱.sqlite`），可以直接转成编辑器能打开的文件：

```bash
python3 亲属谱转JSON.py 镇江亲属谱.sqlite 镇江亲属谱.json --title "镇江亲属称呼谱"
```

然后在编辑器里用「文件 → 打开文件…」载入 `镇江亲属谱.json`。

转换器支持的数据表结构（就是本项目原来那四张表）：

| 表 | 字段 | 对应到编辑器 |
|---|---|---|
| `person` | `pid, callname, note, gender, category` | 成员、姓名、备注、性别、彩色标记 |
| `couple` | `cid, pid_a, pid_b` | 夫妻线（默认为「婚姻」） |
| `child_of_couple` | `couple_id, child_pid` | 夫妻的子女 |
| `child_of_person` | `person_pid, child_pid` | 单亲 / 合称节点的子女 |

说明：原表中 `gender = 'G'` 的**合称节点**（如「堂伯伯 / 堂叔叔」这类代表一类亲属的节点）会转成菱形「性别未填」节点，备注前加「【合称节点】」标记；`category` 字段会转成彩色标记，保留原谱「蓝男、粉女、橙姻亲、紫合称、绿子侄、黄本人」的配色。

编辑器自己存出来的 `.json` 是五张表：

| 表 | 字段 | 说明 |
|---|---|---|
| `people` | `id, name, gender, born, died, …` | 成员 |
| `couples` | `id, a, b, status` | 夫妻线 |
| `links` | `id, child, couple` 或 `child, parent` | 亲子线（`couple` 或 `parent` 指向长辈） |
| `bonds` | `id, a, b, type` | 情感关系线 |
| `kins` | `id, a, b, type, n, text` | **关系线**：`a` 是先点的人、`b` 是后点的人；`type` 取 `birth` / `begotten` / `sibling` / `adopt` / `succession` / `custom`，`custom` 另带 `n`（辈分差）与 `text`（自定义文字） |

手写 `kins` 也可以——比如给两个没录父母的人补一条兄弟关系：

```json
{ "id": "k1", "a": "某人甲", "b": "某人乙", "type": "sibling" }
```

## 十、存档、导出与「仅查看」锁定

顶栏右边有两个下拉按钮：**「文件」**管存档（新建 / 打开 / 保存 / 看数据 / 载入示例），**「导出」**管出图（图片 / 网页 / PDF / 打印）。

| 操作 | 位置 |
|---|---|
| 自动保存草稿 | 自动（浏览器本地） |
| 保存为文件 | 文件 → 保存为文件（Ctrl+S），得到 `.json` |
| 打开文件 | 文件 → 打开文件（Ctrl+O） |
| 查看 / 编辑数据 | 文件 → 查看 / 编辑数据，可直接改 JSON 后「应用」；关系线存在 `kins` 表里 |
| PNG 图片 | 导出 → PNG（2 倍 / 4 倍清晰度） |
| SVG 矢量图 | 导出 → SVG，可用 Illustrator / Inkscape 再编辑 |
| **HTML 网页（只读）** | 导出 → HTML 网页（只读，适合分享），得到一个**单文件网页**，双击就用浏览器打开 |
| **HTML 网页（可编辑副本）** | 导出 → HTML 网页（可编辑副本，能接着改），得到的是**一整个编辑器**，打开就能继续增删改 |
| PDF | 导出 → PDF（A4 或 A3，横向自动适配） |
| 打印 | 导出 → 打印（Ctrl+P） |

导出时可勾选是否包含**图例**与**浅色背景**；导出图片顶部会自动加上家谱名称与分隔线。

**几种导出分别什么时候用**：

| 格式 | 适合 | 特点 |
|---|---|---|
| PNG | 发微信 / 贴到文档里 / 做壁纸 | 位图，放大到一定程度会糊；「4 倍高清」适合大图或喷绘 |
| SVG | 还要再改线条、排版、配色 | 矢量，无限放大不糊，Illustrator / Inkscape / Figma 都能打开 |
| **HTML 网页（只读）** | **发给家人看**、放到自己的网页上 | 一个文件搞定：图表、图例、成员数都在里面，**双击即开、不联网、不依赖任何外部文件**，手机上也能看，宽度不够会自动缩 |
| **HTML 网页（可编辑副本）** | 交给要一起补资料的亲戚、留作阶段性存档 | 打开的是一台完整的编辑器，**带着你导出那一刻的全部家谱数据**，改完还能再导出，见下 |
| PDF | 打印、存档、递交给印刷店 | 内嵌图片，A4 / A3 自适应横向 |
| 打印 | 随手打一张 | 直接调用浏览器打印（Ctrl+P）

### 两种 HTML 网页：只读的和可接着改的

**「只读」**是一张会自己缩放的网页版家谱：只有图、图例和成员统计，没有工具栏，拿到的人只能看、不能改，适合发给长辈或贴到网页上。

**「可编辑副本」**导出的是一台**完整的编辑器**（顶栏、左侧工具栏、右侧属性面板都在），里面已经装好了你导出那一刻的家谱数据。对方双击打开，看到的就是这份家谱，可以直接增删成员、改称呼、重新导出。典型用法：

- 把谱子发给几位亲戚，各人用手机或电脑把自己那一支补全，再发回来；
- 整理到一半先导出一份留着，之后接着改，改完再导出一份（相当于**不需要 Git 的版本快照**）；
- 换一台电脑、换一个浏览器时把家谱搬过去——一个 `.html` 文件就够了，不必再管 `.json`。

几个要点：

- 副本**不会继承「仅查看」锁定**：既然导出它是为了接着改，它就是可编辑的；
- 副本**不会覆盖编辑器的草稿**。编辑器本身、以及每一份导出的副本，各自把自己的自动草稿存在单独的位置（这份文件一个格子、那份文件一个格子），互不干扰，也不会出现「打开副本、结果把主文件改花了」；
- 副本**可以再导出副本**，一层层传下去都没问题；
- 副本里带的是你**导出那一刻**的数据。如果之后又在原文件里改了，原文件不会自动跟着变，需要重新导出一份。

> 一句话挑格式：**给别人看 → 只读网页；给别人改、或者留档 → 可编辑副本。**

### 「仅查看」锁定

整理完一份家谱，想发给家人看、又不想被顺手拖乱，就点顶栏的「**仅查看**」。

锁定后：

- 画布顶部出现黑色横幅「仅查看模式 · 家谱已锁定」，顶栏按钮变成深色的「**已锁定**」；
- 节点四周的 **＋** 号消失，左侧工具栏里所有「增 / 删 / 改」按钮变灰点不动；「自动排列」「撤销 / 重做」一并禁用；
- 右侧属性面板的输入框全部变灰不可编辑，顶部有橙色提示条；
- 双击改称呼、拖动节点、按 `Delete` 都会被拦下，并提示「当前是『仅查看』状态」。

**仍然可以做的**：平移、缩放、适应窗口、框选查看名单，以及全部导出（PNG / SVG / 两种 HTML / PDF / 打印），也可以「打开文件」去看别的谱子。

**这个状态会随文件一起保存**：勾选锁定后按 `Ctrl+S` 存成 `.json`，别人打开这份文件时默认就是只读的。唯独「**HTML 网页（可编辑副本）**」不受它约束——导出的副本一律是可编辑的，理由见上一节。

解除锁定：点画布横幅上的「**解锁**」或顶栏按钮，确认后即可恢复编辑。

> 需要说清楚的是：这是**防误改**，不是加密。锁定状态就写在 `.json` 里，用「查看 / 编辑数据」或文本编辑器把 `"locked": true` 改成 `false` 就解开了。它的用途是提醒和防手滑，不是保护机密。

## 十一、快捷键与鼠标操作

## 十三、已知边界

- 一个人同时有多段婚姻时，会以「绕到下方折线」表示；三段以上关系在极端情况下仍可能出现线条交叉，属正常画法。
- 亲属称呼推算取的是**最短关系路径**。近亲通婚（如堂表亲联姻）会同时存在两条关系路径，此时只显示较短的一条。
- 辈分推算同样取一条路径：近亲通婚时，同一个人可能既是本家的某一辈、又是姻亲的另一辈，程序按先算到的那条定位，可能出现一条线跨两行。断开成两个互不连通的家族时，另外那一家最上面的一辈与中心人物这一支的最上一辈齐平（因为无从判断两家的相对辈分）。
- 极远的旁系（如「表舅父的堂侄」）会退化成「（关系较远）」并给出路径，可手工填写称呼覆盖。
- 「兄弟排行」只在**同一对父母的亲兄弟姐妹**之间生效；堂表亲、继兄弟姐妹即使填了排行，也不会用来比长幼。
- 同一辈里若有人填了出生年、有人只填排行，两种依据会混排（见第八节）。数据本身互相矛盾时（例如排行写着「老大」、出生年却比同辈都晚），以年龄为准。
- 「自动排列」按**固定的亲族次序**（本家 → 奶奶一族 → 外公一族 → 外婆一族，见第四节）摆放家族块，不为了缩短子代线而换边；同一家族内部，子女一律按排行／年龄从左到右，不做交叉优化。数据里若同一个节点挂了两对父母（如「堂伯伯 / 堂叔叔」这类合称节点），两条线都会画出来，其中一条可能较长。
- 「母族关系用淡线」是**画法开关**，只改线的深浅，不改任何数据结构；关掉它不会让「出嫁 / 入赘者画在夫家」这件事发生变化（见第五节）。
- 出嫁 / 入赘者连回本家的那条淡线走**直角**（竖 → 横 → 竖），横向那一段落在「父母那一行」与「子女那一行」之间的空档里；两个家族离得远时它会横穿画面很长一段（镇江那份谱里妈妈那条 2065 px、奶奶那条 1283 px），并且会与沿途的竖线交叉。嫌它碍眼，在「视图」里取消勾选「母族关系用淡线」即可。
- 姊妹位按**排行／出生年**排在兄弟姐妹中间。同一组里几个人都没有出生年、排行又并列时，次序只能按录入先后，位子也就跟着那一个顺序走。
- 「赘 · 入赘」**只有男性可勾**，而且它改的是**门户归属**：勾上后夫妻连子女整体搬进女方家族块，家族块次序跟着重排，不是只多一个小圆章。取消勾选立刻恢复。女性不需要这项资料——出嫁的女儿本来就是按「画在夫家、本家留姊妹位」处理的（见第五节）。
- 框选按**符号中心点**判断是否命中，所以框要罩住圆/方块的中心才算选中。
- 「关系线」**只管辈分，不动结构**：它不会把两个人并进同一个家族块，也不会生成亲子线或夫妻线；已有父母 / 子女 / 夫妻 / 兄弟姐妹算出来的辈分**优先**，关系线只补结构没覆盖到的人。所以同一对人身上，「结构」和「关系线」说法不一致时，以结构为准，那条线会照常画出来但不改行号。
- 同一对人可以画**多条**关系线（互不排斥，也不去重），说法互相矛盾时按先算到的那条定位——一般不需要这么用，画重了直接点标签删掉即可。
- 「关系线」**不参与亲属称呼推算**：只有关系线相连、结构上又走不通的两个人，右侧面板里仍会显示「（关系较远）」或干脆推不出称呼，需要手填。要用称呼推算，还是得把亲子线补上。
- 「自定义」的辈分差 n 收在 **−6 到 +6** 之间（超出按边界算）；「生 / 被生 / 领养 / 过继」固定相差一辈，「兄弟姐妹」同辈。不牵涉关系线的分支走的还是原来那套排版算法，行为和以前完全一样。
- 「仅查看」是防误改的开关，不是加密（见第十节）。
- 「可编辑副本」里装的是**导出那一刻**的数据，之后在原文件里的改动不会自动传过去，需要重新导出一份。它的体积约是普通网页的两倍（里面同时装了编辑器源码和一份源码副本，这样副本才能继续导出副本）；在副本里改完如果不「保存为文件」，改动同样只在这个浏览器里，清浏览器数据会丢。
- 数据存在浏览器本地，**换浏览器或清理浏览器数据会丢失草稿**，重要家谱请用「保存为文件」存一份 `.json`。
